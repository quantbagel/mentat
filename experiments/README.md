# Mentat Experiments

Standalone experiments for the Mentat public reimplementation effort.
Run these from the repo root with `python experiments/<script>.py`.

## Files

| File | What it does |
|------|-------------|
| `compiled_adder.py` | Standalone compiled adder (1,263 params, 100% at any bit width) |
| `compiled_stack_machine.py` | Standalone compiled stack machine (multiple ops, arbitrary instruction streams) |
